# Changelog

## 0.0.1

First public release.

- Muscle Memory Dark and Muscle Memory Light color themes with extra C#, Kotlin and Python styling: teal types, blue async types and awaitable calls, rose parameters, underlined reassigned variables, italic interfaces.
- IntelliJ IDEA's keymap for macOS and for Windows/Linux, focused on navigation, refactoring, run/debug and VCS.
- Inheritance gutter markers for C#, Kotlin and Java, with clickable CodeLens, a right-click menu and hover links.
- Switcher (open files only), Push preview, Go to Super, Next/Previous Method and Select Opened File commands.
- Language-server requests limited to 4 at once, scoped to code on screen, cached and cancelled when outdated.
- Settings: `musclememory.inheritanceMarkers`, `musclememory.inheritanceCodeLens`, `musclememory.csharp.awaitableCalls`.
